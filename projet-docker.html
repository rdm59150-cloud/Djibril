Déploiement d'un service avec Docker (Activité 1)

Contexte : Découverte du fonctionnement de Docker, gestion des images/conteneurs, et déploiement d'une distribution légère Ubuntu avec un accès au service SSH.

Technologies utilisées : Docker Engine Linux (CLI) Conteneurs SSH

Compétences mises en œuvre :

  • Création d'images : Utilisation de la commande commit pour créer une nouvelle image Docker personnalisée à partir d'un conteneur modifié en mode interactif.
  • Sauvegarde locale : Exportation (save) et restauration (load) d'images Docker sous forme d'archives tar.
  • Exposition de services : Lancement de conteneurs en mode détaché (arrière-plan) avec mappage de ports (ex: redirection du port hôte vers le port 22 du conteneur pour le SSH).
  • Diagnostic de base : Utilisation des commandes docker ps, docker top et docker logs pour surveiller l'état et les processus des conteneurs.
