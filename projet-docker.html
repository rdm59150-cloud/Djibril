Déploiement d'un service avec Docker (Activité 1)

Contexte : Découverte du fonctionnement de Docker, gestion des images/conteneurs, et déploiement d'une distribution légère Ubuntu avec un accès au service SSH[cite: 6].

Technologies utilisées : Docker Engine Linux (CLI) Conteneurs SSH

Compétences mises en œuvre (Fin d'activité) :

  • Création d'images personnalisées : Utilisation de la commande commit pour créer une nouvelle image Docker à partir d'un conteneur modifié en mode interactif[cite: 16].
  • Sauvegarde locale : Exportation (save) et restauration (load) d'images Docker sous forme d'archives tar locales[cite: 17].
  • Exposition de services : Lancement de conteneurs en mode détaché (arrière-plan) avec la technique du mappage de port pour rendre un service accessible[cite: 17, 18].
  • Déploiement SSH : Redirection d'un port de la machine hôte vers le port 22 du conteneur pour autoriser les connexions distantes sécurisées[cite: 18].
